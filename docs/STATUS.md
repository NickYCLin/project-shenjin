## 驗證邊界

Browser 的純邏輯測試涵蓋完整遭遇的自然勝利／敗北、前方命中範圍、冷卻、
每招僅一次傷害、閃避體力與無敵、神相消退、神誓回復、第二階段、重置、
時間步長與外圍碰撞。glTF 由 Khronos Validator 驗證。

Browser 和 UE 是不同的實驗實作；玩法與數值可能不同，不能拿 browser 測試結果當作 UE 測試結果。
原生三誓的具體機制請見 unreal/README.md。

## 下一個里程碑：打磨一場戰鬥

1. 安裝 UE5，真實編譯、匯入、Play、打包，修正引擎內發現的問題。
2. 為主角建立骨架與待機／移動／突刺／閃避動畫，完成武器碰撞與命中停頓。
3. 加入敵人招式動畫、鏡頭碰撞和更準確的打擊距離。
4. 以實際玩家試玩驗證好玩程度，再投資寫實雕刻、材質和場景細節。
5. 之後才擴充精英敵人、戰利品、存檔、完整神殿動線與四人合作技術驗證。

尚未包含正式任務、裝備掉落、持續進度、多人、反作弊、上架與付費系統。
不以此原型宣稱 3A 品質、多人架構完成或正式版本已可上架。
