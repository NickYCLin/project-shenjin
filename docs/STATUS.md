# 失落神殿 · v0.2 開發狀態

這是持續打磨中的單人戰鬥與美術原型。v0.2 是本次開發範圍名稱，不代表正式發行、商店上架或已達 3A 品質。

## 已實作內容

- **骨架角色**：主角與四臂守衛各有可編輯 Blender 來源、skin、關節權重與 GLB / FBX 動畫，共 13 支 clips。主角包含待機、步行、突刺、閃避、受擊、死亡；守衛另有預備、下劈、收招。曲面盔甲、刻紋、分節手指與布褶已加入，細節與重建方式見[角色動畫文件](../tools/blender/ANIMATION.md)。
- **武器與戰鬥時序**：長槍掛在 `WeaponSocket`；`WeaponTip` 提供跨引擎朝向。Browser 普通突刺長 0.55 秒，0.20 秒才判定命中；閃避可取消待命中攻擊。守衛 Slam 在 0.30 秒末端造成一次傷害，保留預警鎖定落點與階段快照。
- **戰鬥回饋**：命中停頓、受擊閃光、粒子、傷害數字、可關閉鏡頭震動；勝敗與重開、鍵鼠操作、暫停、失焦暫停、合成音效仍可用。固定步長時鐘會計入停頓的實際時間，避免低幀率額外拖慢戰鬥。
- **場景與鏡頭**：Browser 改用 `temple-v2.glb`，加入雕刻神殿、柱廊、祭壇與山岩層次。鏡頭使用獨立的 37 個簡化碰撞盒與五路探測；這些是鏡頭碰撞，不是角色物理或尋路網格。場景重建見[神殿 v2 文件](../tools/blender/TEMPLE_V2.md)。
- **PBR 材質**：加入石材、地面、岩壁與金屬的基底色、法線、粗糙度來源；角色以自訂基底色搭配金屬法線與粗糙度。GLB 包含貼圖，Blender 來源保留可編輯材質。原創模型與程式採 MIT，第三方貼圖來源另按 CC0 記錄於[素材清單](../art/textures/sources.json)。
- **UE 原生管線**：新增獨立 skeletal importer、固定 asset 路徑、完整 clip / Skeleton 校驗、Single Node 播放、武器骨骼掛載與 static fallback。缺少引擎時啟動腳本會明確失敗；詳見[UE 流程及未驗證項目](../unreal/README.md)。

Browser 與 UE 是各自實作的實驗；Browser 有兩種神誓，UE 有三種，部分攻速、範圍、傷害與階段數值仍不同。UE 既有 static 場景匯入目前使用 `temple.fbx`；`temple-v2.fbx` 尚待在真正的 Unreal Editor 接入與驗證。

## 本次已確認的證據

- `art/exports/animation-manifest.json` 記錄 13 支 clips、4 次 Blender GLB / FBX 回匯、關節權重、原地 Root、循環首尾與武器軸向檢查。這是 Blender 資料驗證，不能視為 Unreal 匯入通過。
- 本機完整 `npm test` 的 39 項測試通過。涵蓋實際 GLB 關節播放、末端砸擊、下劈中閃避、接觸前擊殺取消砸擊、完整勝敗流程，以及暫停時間與鏡頭基本碰撞。
- 重複命中停頓測試在 15 / 30 / 60 / 144 FPS 的 10 秒輸入內均產生 551 個模擬 ticks；這是計時一致性檢查，不是渲染 FPS 測量。
- 12 份本機來源貼圖的大小與 SHA-256 已核對 `sources.json`；目前匯出的場景與角色 GLB 確實包含 image、mesh，角色亦包含 skin / animation 資料。
- UE 來源契約檢查會輸出 JSON，涵蓋 Python 語法、命名、資產路徑與 cook 設定；**C++ 編譯、UHT、Editor 匯入、PIE、封裝皆尚未執行**。

- 7 份 GLB 通過 Khronos Validator，全部 0 errors / 0 warnings；格式檢查與 production build 通過。
- Chrome 實際載入新版模型與材質，檢查開始、自然敗北、重試、神相、鍵盤操作與暫停；主控台未見 warning / error。實際畫面見[截圖](browser-prototype-v2.jpg)。完整勝利流程目前由規則模擬測試覆蓋，尚未以人工操作完成。
- 尚未量測完整渲染 FPS、GPU 記憶體或各硬體效能；39 項測試通過不代表這些效能項目通過。GitHub CI 狀態以 repository 的 workflow badge 與該 commit 的 Actions 為準。
